# LOTRO PT-BR — instalador Windows

Distribuição por **Zeca(TicNervoso)**.

[Baixar instalador 0.2.2-preview (ZIP)](https://github.com/Yuki-collab-hash/lotro-ptbr-installer/releases/download/v0.2.2-preview/LOTRO-PTBR-Windows-0.2.2-preview.zip) · [Checksum SHA-256](https://github.com/Yuki-collab-hash/lotro-ptbr-installer/releases/download/v0.2.2-preview/LOTRO-PTBR-Windows-0.2.2-preview.zip.sha256)

1. Baixe e **extraia todo** o ZIP no Windows.
2. Feche o LOTRO e seu launcher.
3. Abra `LOTRO-PTBR/LOTRO-PTBR.exe` e confira a pasta do jogo.
4. Clique em **Verificar instalação** e depois em **Instalar tradução**.
5. Inicie o jogo mantendo **English** como idioma no launcher.

A tradução inclui revisões até o lote 15 e o primeiro recorte Blackwold (Lobos Negros). O aplicativo faz backup do DAT antes de substituir o arquivo e oferece restauração para a mesma versão do jogo.
